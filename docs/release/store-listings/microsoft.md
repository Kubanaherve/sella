## Short description

Sales, stock and credit for a shop.

## Description

Sella is shop software for recording a sale, stock, and customer credit (Ideni). The same web app runs in an Electron window on Mac and Windows. That window is not a second product and it is not signed for the Microsoft Store yet.

Subscription payment is on the website through MTN MoMo. Do not add an in-app purchase until a Microsoft billing product exists and is checked on the server.
