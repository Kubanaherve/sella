# Sella glass + solid SVG pack

Installed from `Sella-Glass-and-Solid-SVGs.zip`.

## Locations

- Design source: `design/sella-brand/`
- Runtime assets: `public/brand/sella-brand/assets/`
- Helper: `src/lib/sellaBrand.ts`
- Components: `SellaBrand`, `BrandMark`, `SellaLogoMark`

## Usage rules

| Placement | Asset |
|-----------|--------|
| Auth / welcome | `stacked-glass-light` |
| App headers / More | `mark-glass-light` or `tile-glass-light` |
| Compact 16–24px | `micro-*` |
| Brand name alone | `wordmark-glass-light` |
| Splash logo fade-in | `mark-glass-light` |
| Splash **writing** animation | unchanged liquid-glass script PNG (`SellaSignature`) |

Keep glass finishes by default. Use solid black/white only on dense contrasting panels.
