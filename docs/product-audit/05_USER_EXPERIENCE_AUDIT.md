# 05 — Ordinary Shop Owner UX Audit

**Audit date:** 2026-11-12  
**Persona:** First-time smartphone business user in Rwanda; Kinyarwanda preferred; low patience for files/PDFs.

## Essential journey step counts (estimated from code flows)

| Goal | Approx taps | Friction |
|------|------------:|----------|
| Add product + price + stock | 4–6 | Acceptable |
| Sell paid item | 5–8 | Medium |
| Credit sale with phone | 7–10 | Phone validation critical |
| Partial payment | 4–6 | OK |
| See who owes | 1–2 | Strong |
| WhatsApp reminder + PDF | 2–3 ideal | **Device-unverified** |
| Understand today money | 1 | Wording may confuse sales vs cash |

## Can they learn in 10–15 minutes?

**Partially.** Core debt list + sale is approachable. Full mastery of reports, billing, import, assistant exceeds 15 minutes without guided tour.

## Recommendations (product, not fluff)

1. First-run checklist: Add product → Make sale → Add credit → Send reminder.  
2. Contextual one-sentence help under primary CTAs.  
3. Undo window for mistaken debt delete (currently hard delete).  
4. Larger primary buttons already improving; keep secondary quieter.  
5. Voice input: **not** recommended as priority (complexity > value now).  
6. Keep WhatsApp status copy non-technical (“Preparing customer statement…”).

## Financial mistake risks

- Deleting debt restores stock but previously left sales (fixed locally this audit).  
- Wrong phone → wrong WhatsApp (validation added; still need UX stop).  
- Partial payment race on cloud.  
- Confusing “sales volume” vs “money collected”.
