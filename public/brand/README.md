# Sella brand assets (neon S-bag)

Official glossy neon shopping-bag **S** mark used across app, PWA, PDFs, and store listings.

| File | Use |
|---|---|
| `sella-icon.png` / `.jpg` | App icon (full squircle) |
| `sella-logo.png` / `.jpg` | Auth / marketing heroes |
| `sella-icon-192.png` / `sella-icon-512.png` | PWA sizes |
| `sella-splash.png` | Neon field splash reference |
| `sella-glass-script.png` | Handwritten glass-bold “Sella” (transparent) |
| `sella-glass-script-hero.jpg` | Same script on blue glass field |
| `sella-glass-ambient.jpg` | Soft periwinkle glass app/splash field |
| `sella-glass-lockup.jpg` | Icon + gel wordmark lockup reference |

Source copies also live in `src/assets/brand/` for Vite imports via `BrandMark`.
Native icons/splash are generated from `resources/` + `assets/` via `npm run assets:generate`.
